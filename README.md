# Trendyol Organizer Product Images

Public product-image assets for the `Tezgah Üstü Kaşıklık ve Kepçelik Mutfak Organizeri` listing.

- Seven color-specific folders are kept separate.
- Every published image is 1200 × 1800 pixels at 96 DPI.
- Gallery order is encoded in the numeric filename.
- Product assets are published for marketplace delivery; all rights are reserved.

The `manifest.json` file records the relative path, color, dimensions, size, and SHA-256 checksum of every image.
